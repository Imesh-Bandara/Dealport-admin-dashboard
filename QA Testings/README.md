# QA Testings

QA artifacts for the Dealport Admin Dashboard, organized by area:

- **Backend Testings/** — automated Playwright API test suite (smoke +
  regression) run against the live NestJS backend, plus a results doc.
- **Frontend Testings/** — reserved for a separately supplied frontend
  test document.
- **Smoke and Regression Testing/** — a combined summary report drawn
  from the same backend Playwright suite, split out by test category.
